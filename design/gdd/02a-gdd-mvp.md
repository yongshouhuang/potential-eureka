# 仙侠卡牌项目 · Phase 2 系统设计（pass 1：MVP 5 系统 GDD）

> 阶段：Phase 2 系统设计 · 第一轮（pass 1）｜ 范围：仅 MVP 5 系统深做，全系统 GDD 框架留 pass 2
> 基线：Godot 4.x（2D-first，3D 演出余量）｜ 双端 PC 横屏(≥1024px) + 移动竖屏(<768px)｜ 评审 solo/lean
> 支柱：P1 抽养一体 / P2 御剑修真 / P3 构筑随心
> 关联：01-concept.md（概念）、art/art-bible.md（视觉规范）

## A. 系统拆解与依赖排序

MVP 5 个系统存在严格的资源/数据上下游关系，实现顺序必须自底向上：

- 经济闭环是底座（最优先）。它定义全部货币与资源、产出源与消耗 sink；其余 4 个系统全部向它取资源、向它回流产出，没有经济 schema 其他系统无从对接。
- 抽卡召唤依赖经济（消耗符箓/灵玉），其唯一产出是「式神」——这是后续所有玩法的素材。
- 养成系统依赖抽卡（需要式神对象）+ 经济（消耗灵气/丹/石），把式神变成「带最终属性与技能的可战单位」。
- 五行构筑+推图战斗依赖养成（读取养成后的式神最终属性/技能与五行/羁绊标签），是循环的可玩终点。
- 双端 Demo 串起全部，依赖前 4 个系统的接口与数据表，作为集成出口与 pass 2 骨架。

实现先后顺序：① 经济闭环 → ② 抽卡召唤 → ③ 养成系统 → ④ 五行构筑+推图战斗 → ⑤ 双端 Demo。
（说明：①与②可小步并行——经济先定货币表与预算，抽卡先定卡池/概率/保底结构，二者在「符箓消耗接口」处合拢即可。）

## B. 逐系统 GDD（严格八节）

### B1 · 基础资源经济闭环

① 目标
定义 MVP 全部货币/资源、产出源与消耗 sink，形成「抽卡→养成→战斗→产出→回流抽卡」自洽闭环，让留存飞轮可转；为后续平衡监控提供预算基线。

② 输入
- 产出源：日常任务、推图通关、章节首通、Boss 掉落。
- 消耗 sink：抽卡（符箓/灵玉）、养成（灵气/突破丹/觉醒石）。

③ 机制
- 货币分层：硬通（灵玉，可购，MVP 不强制）、软通（符箓，玩法产）、养成资源（灵气/突破丹/觉醒石，玩法产）。
- 日/周预算硬上限，控通胀；回流路径：战斗产符箓→抽卡→式神→养成→更强→推更高难→更多产出。

④ 数值（区间/方向，非精算）
- 符箓：日软预算 10–15（可攒可花，已修正 pass1 下限冲突）；另单列「每日免费十连」为独立赠送额度 10 符箓/日，不计入软预算；十连 = 10 符箓。（修正依据见 02b-gdd-full.md 开头「pass1→pass2 承接修正」）
- 灵气：日产 ~2000（够 1–2 式神升阶）。
- 突破丹：周产 ~5（或 ~1/日）。
- 觉醒石：仅 Boss 掉，稀有（周 1–2）。
- 灵玉：MVP 仅预留商城入口，不做深度付费。

⑤ 反馈
- 视听：资源获得飘字（青碧 #4FA39B 灵力色）、邮箱/奖励领取玉质感动效（art-bible §7）。
- 数值：顶部状态栏货币实时计数（等宽数字，art-bible §3）、日/周获取上限提示。

⑥ 边界（不做什么）
MVP 不做：交易行、玩家间赠送、付费深度商城（仅预留灵玉入口）、赛季通行证复杂经济、法宝/灵宠独立货币线。

⑦ 依赖
- 依赖：无（最底层）；数据配置表。
- 被依赖：抽卡、养成、构筑+战斗、Demo 全部（资源底座）。

⑧ 风险 + 缓解
- 风险：经济通胀/萎缩（产出 sink 失衡）→ 留存断裂或逼氪。
- 缓解：日/周预算硬上限；保底/半价控节奏（见 B2）；MVP 即埋点监测「产出/消耗比」与各环节转化率，预留调参接口（与 B5 埋点联动）。

▶ 双端适配要点：货币状态栏 PC 放角落、移动常驻顶部（art-bible 断点：≥1024 多栏 / <768 单列）；数值用 tabular nums 防跳动。

### B2 · 抽卡召唤（含基础式神图鉴 10–15 式神 + 自带短叙事）

① 目标
作内容入口与收集起点，让玩家获得式神并即时看到「抽养一体」叙事钩子（P1）；提供可预期出货节奏与保底，保障留存与付费底线。

② 输入
玩家点击「召唤」→ 选卡池（MVP：常驻 + 新手）→ 单抽/十连；消耗符箓（或灵玉）。

③ 机制
- 卡池：常驻池（全档位）+ 新手池（前 20 抽半价、必出指定 SR 起步式神）。
- 概率公示：SSR 2% / SR 10% / R 35% / N 53%。
- 保底：50 抽小保底（SSR 概率升至 50%），90 抽大保底必出 SSR；保底计数 MVP 不跨池继承。
- 抽养一体：每次出货式神附带「羁绊序章」短叙事（1–2 屏），建立初始情感连接（呼应 01-concept §5 动词「羁」）。

④ 数值（区间/方向）
- 式神档位：N/R/SR/SSR 四档（MVP 10–15 式神铺满）。
- 稀有度基线属性（ATK 区间）：N 60–80 / R 85–105 / SR 110–135 / SSR 140–170（具体随 B3 养成曲线收敛）。
- 保底：50 软 / 90 硬；新手池半价门槛 20。

⑤ 反馈
- 视听：抽卡演出（卡牌翻面 / 灵光升腾，SSR 用 A3「悬浮法宝灵光」意象 + 紫宸 #8B6DB3 虹光，art-bible 锚点4）；稀有度用「颜色 + 边框纹理 + 角星数(1/2/3)」三重冗余（art-bible §8 色盲友好）。
- 数值：出货后图鉴点亮、羁绊序章弹窗、保底进度条更新。

⑥ 边界（不做什么）
MVP 不做：限定卡池、跨池保底继承、法宝独立池、皮肤、长演出抽卡动画、P2P 赠送。

⑦ 依赖
- 依赖：经济（符箓/灵玉）、图鉴与叙事数据（式神绑定短叙事）。
- 被依赖：养成（式神来源）、构筑+战斗（构筑素材）。

⑧ 风险 + 缓解
- 风险：首抽挫败（R1 相关）、数值通胀（R1）。
- 缓解：新手半价保底池降挫败；出货即叙事钩子提情感；稀有度 ≠ 绝对战力——靠五行/羁绊补正（B4）与机制新颖性（R1 缓解）避免老卡报废。

▶ 双端适配要点：PC 横屏多卡并排预览 + 十连动画展开；移动竖屏单卡纵向流、十连折叠为结果列表，保底进度条收为图标。操作：PC 悬停看概率/详情，移动长按看概率（触控热区 ≥44×44px，art-bible §7）。

### B3 · 养成系统（升级 / 突破 / 技能觉醒）

① 目标
把抽到的式神从「抽到」养成「变强/飞升」，兑现 P2 御剑修真的成长爽感；提供清晰胜任感反馈，产出可供构筑与战斗使用的最终数值。

② 输入
玩家选式神 → 选养成动作（升级/突破/觉醒）→ 消耗灵气/突破丹/觉醒石（来自 B1）；突破可选消耗同名碎片。

③ 机制
- 升级：耗灵气提升等级，线性提升 HP/ATK。
- 突破：阶级跃迁（1→6 阶），每阶解锁/强化被动槽，需突破丹 + 碎片。
- 技能觉醒：达阶位门槛后觉醒主动技（改写机制而非纯数值），提供 P3 构筑策略增量。
- 分支：高阶突破可选「剑修/体修」方向（不同被动），给自主感（呼应 01-concept SDT 自主感）。

④ 数值（区间/方向）
- 等级上限随突破阶：1 阶 Lv20 → 6 阶 Lv80。
- 升级：每级 ATK +2~3%、HP +2~3%（线性）。
- 突破：每阶全属性 +8~12%，解锁 1 被动槽（上限随阶增）。
- 觉醒：主动技效果改写（例：火系 SSR 觉醒后「灼烧」可叠层）。
- 养成资源需求随阶指数增长（控节奏，与 B1 预算对齐）。

⑤ 反馈
- 视听：升级光粒汇聚、突破「飞升」特效（御剑意象 A1）、觉醒技能演示；紫宸/鎏金 #CBA75C 光效按阶位升级（art-bible 稀有度）。
- 数值：属性面板实时跳动、战力值(Combat Power)变化、解锁提示（红剑/蓝盾/绿十字三重，art-bible §8 不依赖纯色）。

⑥ 边界（不做什么）
MVP 不做：好感度系统、皮肤养成、法宝/灵宠独立养成线（留扩展）、转生/共鸣保值（R1 缓解项，MVP 仅预留接口）。

⑦ 依赖
- 依赖：抽卡（式神来源）、经济（资源）、数据表（成长曲线）。
- 被依赖：构筑+战斗（读取最终属性/技能/五行/羁绊标签）。

⑧ 风险 + 缓解
- 风险：养成疲态（R2）、数值通胀（R1）。
- 缓解：分支方向（剑修/体修）+ 简化剧情化养成事件（R2）；节奏曲线控制；预留保值接口（R1）。

▶ 双端适配要点：PC 双栏（左式神列表 / 右详情面板）；移动底部 Tab 切换，属性面板折叠可展开。操作：PC 拖拽分配/批量升级，移动点按 + 「一键养成」按钮（大热区）。

### B4 · 五行相克卡组构筑 + 1v1 PvE 推图战斗（主线前 3 章）

① 目标
让玩家用养成结果按五行+羁绊自由构筑，在 1v1 PvE 推图验证策略，兑现 P3 构筑随心；用网状克制压制主导策略（R5）；前 3 章提供叙事与难度曲线。

② 输入
- 构筑：从已拥有式神选上阵（4 式神 + 1 法宝位），点选/拖拽编队。
- 战斗：进章节关卡 → 回合制对战，玩家选技出招。

③ 机制
- 五行网状克制：金→木→土→水→火→金（循环相克）；另设相生（生）给小幅增益。克制方伤害 ×1.25–1.35，被克 ×0.7–0.8。
- 羁绊连携：特定式神同队触发连携（如「剑宗三人」攻 +15%），奖励成队养成（P1 抽养一体引申）。
- 战斗：回合制，行动条/能量，玩家选技；式神技能带五行属性触发克制。
- 章节：前 3 章，每章 8–10 关递增，含 1 章节 Boss；首 3 章刻意铺不同五行敌人做教学。

④ 数值（区间/方向）
- 卡组规模：4 式神 + 1 法宝位（MVP）。
- 克制倍率：克制 1.25–1.35 / 被克 0.7–0.8。
- 连携：2 式神 +8~12% / 3+ 式神 +15~20%。
- 单场时长：2–4 分钟（移动友好）。
- 关卡产出：每关符箓 1–3，章节首通额外奖励（回流 B1）。

⑤ 反馈
- 视听：五行技能特效（A5「五行符文阵」意象，按属性配色 + 形状不靠色，art-bible §8）；克制命中「克制！」浮字；连携触发横幅；Boss 战用 3D 演出余量。
- 数值：伤害数字（等宽）、克制标识、关卡星级、首通奖励弹窗。

⑥ 边界（不做什么）
MVP 不做：PvP 竞技（核心层）、秘境 Roguelite（核心层）、多单位大战场、玩家自定义关卡。

⑦ 依赖
- 依赖：养成（最终属性/技能/五行/羁绊标签）、经济（关卡产出）、抽卡（式神池）。
- 被依赖：Demo（循环终点）、经济（产出回流）。

⑧ 风险 + 缓解
- 风险：主导策略（R5）、数值通胀（R1）、战斗节奏冗长。
- 缓解：网状克制 + 连携组合 + 平衡监控（B5 埋点）；单场时长上限；前 3 章教学铺不同五行敌人；发现偏差快速调参（R5）。

▶ 双端适配要点：PC 横屏编队拖拽 + 战场大视野（中栏）；移动竖屏编队网格 + 战斗竖向手牌。操作：PC 右键快捷、移动滑动出招。HUD 移动端只留关键数值，技能按钮大热区（≥44×44px）；五行用「图标 + 形状(圆/三角/方)」冗余（art-bible §8）。

### B5 · 双端可运行核心循环 Demo

① 目标
用 Godot 4.x 串起「抽→养→筑→战」最小可玩闭环，在 PC 横屏 + 移动竖屏双端跑通，验证手感与适配基线，作为 pass 2 全系统骨架。

② 输入
- 开发者：Godot 场景/脚本（主菜单→抽卡→图鉴→养成→编队→推图→结算→资源）。
- 玩家：触控（移动）/ 键鼠（PC）双输入。

③ 机制
- 一条可走通核心路径：含 1 次抽卡、1 式神养成、1 套编队、前 3 章首关战斗。
- 响应式 UI：同一套 UI 描述，按端切换布局（横屏多栏 / 竖屏单列）。
- 云存档接口预留（MVP 本地存档，云接口留桩）。

④ 数值（基线，非精算）
- 沿用 B1–B4 初版区间；帧率目标 PC 60 / 移动 30–60。
- 包体目标：MVP < 300MB（2D 资源为主）。

⑤ 反馈
- 视听：完整核心循环可交互；旋转/分辨率切换不崩。
- 数值：埋点日志——抽卡→养成→战斗→回流 各环节转化率（MVP 仅日志，供 B1 经济监控复用）。

⑥ 边界（不做什么）
MVP 不做：完整 15 式神、全 3 章、美术终稿（用占位/简版）、音频终稿、云存档实装（留桩）。

⑦ 依赖
- 依赖：B1–B4 的接口与数据表。
- 被依赖：无（集成出口）；为 pass 2 全系统提供骨架与适配基线。

⑧ 风险 + 缓解
- 风险：双端适配返工（R3）、性能不达标。
- 缓解：MVP 即定响应式 UI 基线 + 输入抽象层；架构预留云存档（R3）；性能预算前置（包体/帧率）。

▶ 双端适配要点：本系统即适配验证点——响应式断点 ≥1024 横屏多栏 / 768–1024 混合 / <768 竖屏单列（art-bible §7）；输入抽象层统一触控与键鼠；首屏即验证旋转/分辨率切换稳定性。

## C. 跨系统数据流（闭环）

C1 · 资源：产出 → 回流
[经济 B1] 定义货币(符箓/灵玉/灵气/丹/石)
   │  符箓 ──消耗(sink)──► [抽卡 B2] ──产出式神──►
   │  灵气/丹/石 ──消耗(sink)──► [养成 B3] ──产出"最终式神"──►
   │                                                  │
   └── [推图战斗 B4] ──产出(符箓/丹/石)──► 回流经济(产出源)
           ▲                                        │
           └──── 战斗消耗[构筑 B4]卡组 ◄─────────────┘
- 抽卡耗符箓 → 式神；养成耗灵气/丹/石 → 更强式神；战斗产符箓/丹/石 → 回流经济 → 再抽卡，闭环成立。

C2 · 养成数值 → 构筑与战斗
- B3 养成后式神携带：最终ATK / 最终HP / 技能(含觉醒改写) / 五行标签 / 羁绊标签 / 阶位。
- 构筑(B4)读取这些构成卡组属性总和与连携判定；战斗(B4)逐式神读取实时属性与技能效果参与结算。

C3 · 构筑 → 战斗结果
- 卡组五行构成 ⇒ 决定对敌克制关系 ⇒ 命中倍率(×1.25–1.35 / ×0.7–0.8)。
- 同队羁绊 ⇒ 连携加成(+8~20%)。
- 玩家操作(选技) + 属性 + 克制 + 连携 ⇒ 每回合伤害 ⇒ 累积击杀 ⇒ 胜负 ⇒ 战利品回流(C1)。
