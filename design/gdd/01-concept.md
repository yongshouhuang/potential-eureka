# 仙侠卡牌项目 · 游戏概念文档（Phase 1 概念孵化）

> 定位：养成收集型仙侠卡牌对战（Xianxia Card Battler）
> 参考锚点：《原神·七圣召唤》的轻量对战手感 + 《阴阳师》式神收集与养成
> 引擎：Godot 4.x（2D-first，保留 3D 演出余量）｜ 平台：PC Steam + 移动 iOS/Android（云存档）
> 评审强度：solo / lean（聚焦决策与方向，质量门从简）

## 1. 核心支柱（Design Pillars）

三条支柱须可指导后续一切取舍——当功能冲突时，优先保支柱。

**P1 · 抽养一体**
主张：抽卡即叙事，养成即成长。
阐释：每一张抽到的式神/法宝都自带身世、羁绊与成长线，使"收集"成为"养成"的起点而非终点，杜绝抽卡沦为纯概率赌博的空虚感。

**P2 · 御剑修真**
主张：以"凡人→真仙"的问道飞升为核心幻想。
阐释：用东方仙侠的御剑、宗门、突破飞升提供持续可感的成长爽感，让每一次推图与突破都兑现"变强、超脱"的幻想满足。

**P3 · 构筑随心**
主张：五行相克 + 羁绊连携，让"战"成为策略表达。
阐释：高自由度卡组构筑与网状克制，确保战斗是玩家的自我表达而非数值碾压，从机制上压制主导策略。

## 2. MDA 框架分析

### 2.1 Mechanics（候选核心机制，5–8）
1. **抽卡召唤**：消耗灵玉/符箓召唤式神与法宝，是内容入口。
2. **养成突破**：升级、突破（阶级跃迁）、技能觉醒，提供线性成长反馈。
3. **卡组构筑**：在式神+法宝池中按五行与羁绊组合出战卡组。
4. **五行相克**：金木水火土网状克制（非单一石头剪刀布），制造环境轮转。
5. **羁绊连携**：特定式神同场触发连携技/被动，奖励"养出一队"而非"养一卡"。
6. **秘境 Roguelite**：随机地图、随机事件、遗物构筑，注入变数与探索。
7. **剧情推图**：主线+宗门支线，承载叙事与世界观投放。
8. **宗门竞技**：PvP 竞技场、段位排行、宗门协作，承载长线社交与目标。

### 2.2 Dynamics（涌现的核心玩法动态，2–3 段）
- **增长螺旋**：抽卡→养成→构筑→推图/秘境→产出资源→回流抽卡，形成一个自洽的留存飞轮。关键不是单次循环快，而是每转一圈都让玩家"更懂、更强、更牵挂"，从而把概率消费转化为情感投资。
- **策略涌现而非数值涌现**：五行相克（网状）与羁绊连携（关系网）叠加，使任何单卡都无法"通吃"——环境会随版本与新卡轮转，迫使玩家持续重组卡组。这从机制层面压制了"一招鲜"的主导策略，让构筑成为长期智力游戏。
- **确定性与变数的张力**：卡组构筑提供稳定的"表达自我"，秘境 Roguelite 注入不确定的"临场应变"，二者交替满足玩家的掌控欲与惊喜欲。剧情推图负责慢节奏叙事，竞技场负责快节奏验证，形成呼吸感。

### 2.3 Aesthetics（8 种乐趣的取舍）
**主打（核心体验必须兑现）：**
- **Fantasy（幻想）**：御剑修真、飞升超脱是品类根基，必须强兑现。
- **Narrative（叙事）**：抽养一体决定了"角色有故事"是留存核心。
- **Expression（表达）**：构筑随心，卡组即玩家个性的外化。

**兼顾（锦上添花，按需投入）：**
- **Discovery（探索）**：秘境 Roguelite 与世界观词条发现。
- **Challenge（挑战）**：竞技段位与高难秘境的难度曲线。
- **Social（社交）**：宗门、助战、竞技场的轻社交。

**有意弱化**：Submission（沉浸/养成消磨）非本项目目标，不做放置挂机主循环；Sensation（感官）仅作为 3D 演出余量点缀，不喧宾夺主。

## 3. 玩家心理学

### 3.1 自我决定论（SDT）
- **自主感（Autonomy）**：卡组自由构筑、突破方向分支（如"剑修/体修"路线）、秘境路线与遗物取舍，让玩家感到"是我的选择"。
- **胜任感（Competence）**：清晰的升级/突破即时反馈、平滑难度曲线、PvE 章节通关与 PvP 段位晋升，持续证明"我在变强"。
- **关联感（Relatedness）**：式神羁绊叙事建立玩家与角色的情感纽带，宗门与剧情同伴关系提供"属于某个世界"的归属感。

### 3.2 Bartle 玩家类型
- **主服务：Achiever（成就型）**——图鉴收集、突破飞升、章节通关、竞技排名，长线留存靠成就与目标驱动，是付费与日活基本盘。
- **兼顾：Explorer（探索型）**——秘境 Roguelite 与世界观/词条发现满足"想知道后面有什么"；**Socializer（社交型）**——宗门、助战、竞技提供轻社交与目标共担。
- **Killer（对抗型）**仅通过竞技场浅层满足，不作为设计重心。

## 4. 范围分层（Scope Layering）

### MVP（首玩验证最小集，3–5）
1. 抽卡 + 基础式神图鉴（10–15 式神，含自带短叙事）。
2. 养成系统（升级 / 突破 / 技能觉醒）。
3. 五行相克卡组构筑 + 1v1 PvE 推图战斗（主线前 3 章）。
4. 基础资源经济闭环（抽卡资源产出→回流）。
5. 双端可运行的核心循环 Demo（验证手感与适配基线）。

### 核心（上线必备，3–5）
1. 羁绊连携系统（式神关系网与连携技）。
2. 秘境 Roguelite 模式（随机地图+事件+遗物）。
3. 完整主线剧情 + 宗门支线弧。
4. PvP 竞技场 + 段位/排行。
5. 云存档 + 双端统一 UI 适配（响应式框架）。

### 扩展（长线运营内容，3–5）
1. 宗门社交深化（宗门战、协作秘境、助战共享）。
2. 法宝 / 灵宠独立养成线。
3. 季节性活动 + 限时主题卡池。
4. 高难团本 / World Boss（多人协作）。
5. 玩家 UGC 卡组分享与社区赛事。

## 5. 动词优先（Core Verbs）

| 动词 | 英文 | 玩家动作 |
|------|------|----------|
| 抽 | Summon | 消耗资源召唤式神/法宝，开启一段新缘分 |
| 养 | Cultivate | 升级、突破、觉醒，把式神从"抽到"养成"飞升" |
| 筑 | Build | 按五行与羁绊组装出战卡组，表达策略 |
| 战 | Battle | 推图 / 闯秘境 / 上竞技场，验证构筑与实力 |
| 羁 | Bond | 解锁并深化式神羁绊叙事，建立情感连接 |

## 6. 视觉锚点（供美术方向，3–5）

**A1 · 青衫御剑少年**
- 风格关键词：工笔水墨、大面积留白、衣袂飘举。
- 参考意象：传统仙侠插画、剑侠情缘、宋代人物画。
- 情绪基调：清冷孤高、自由出尘（玩家的自我投射）。

**A2 · 水墨描金卡牌框**
- 风格关键词：描金水墨、留白构图、碑拓质感。
- 参考意象：宋代院体花鸟、金石碑拓、古籍函套。
- 情绪基调：典雅收藏感（让"抽到"有仪式与珍重）。

**A3 · 悬浮法宝灵光**
- 风格关键词：半透明发光、粒子流光、符纹流转。
- 参考意象：道教法器、敦煌飞天、唐卡背光。
- 情绪基调：神秘崇敬（强化"法宝即神物"的幻想）。

**A4 · 宗门山门云海**
- 风格关键词：青绿山水、层叠云雾、远近视差。
- 参考意象：《千里江山图》、武当/峨眉山势。
- 情绪基调：宏大归属感（"我属于这座仙门"）。

**A5 · 五行符文阵**
- 风格关键词：篆隶符箓、动态流转、五行配色。
- 参考意象：太极八卦、苗族银饰、星图。
- 情绪基调：玄妙秩序感（战斗克制关系的视觉化）。

## 7. 风险与缓解（概念层）

**R1 · 抽卡数值通胀**
风险：长线越强卡越需更强数值，老卡报废、逼氪。
缓解：以"机制/羁绊新颖性"而非纯数值驱动新卡；设保值线（老卡可转生/共鸣）、环境轮转让旧卡有上场场景。

**R2 · 养成疲态**
风险：长线养成重复刷本，玩家倦怠流失。
缓解：突破方向分支（不同修道路线）+ 剧情化养成事件，避免纯数值 grind；用羁绊叙事给养成注入意义。

**R3 · 双端适配成本**
风险：PC/移动在 UI 密度与操作范式上差异大，后期返工贵。
缓解：MVP 即定响应式 UI 基线（统一交互范式、安全区/字号规范），架构预留云存档与输入抽象。

**R4 · 内容产能瓶颈**
风险：重剧情重内容，式神/剧情产出跟不上留存消耗。
缓解：模块化叙事（通用模板+变量），优先做"抽养一体"的角色自带短剧情降低单卡成本；秘境 Roguelite 用程序化组合摊薄内容压力。

**R5 · 主导策略（Dominant Strategy）**
风险：某套卡组/流派数值或机制碾压，扼杀构筑多样。
缓解：五行相克做成网状克制 + 版本环境轮转；MVP 起即建立平衡监控与克制数据统计，发现偏差快速调参。

---

【一句话总结】本概念以"抽养一体 / 御剑修真 / 构筑随心"三大支柱统摄仙侠卡牌的留存飞轮与策略深度，并已在概念层预置对数值通胀、养成疲态、双端成本、内容产能与主导策略五类风险的缓解方向。
