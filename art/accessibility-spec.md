# 仙侠卡牌 · 可访问性规格（Accessibility Specification）
**项目**：仙侠卡牌（Xianxia Card Battler）　**阶段**：Phase 3 技术搭建（架构接口预留）　**引擎**：Godot 4.x（2D-first）　**平台**：PC Steam（横屏 ≥1024px）+ 移动 iOS/Android（竖屏 <768px）　**评审**：solo / lean　**编写**：art-director 林绘澄　**对齐**：art/art-bible.md §8、design/gdd/02a·02b 可访问性要点

## 0. 范围与基线
- 本规格将 Phase 1 美术圣经 §8 的「solo 轻量基线」升级为**正式三级分级**（Basic / Standard / Comprehensive），作为工程侧 Phase 3 架构预留可访问性接口的契约。
- 可访问性为双端上线底线，不是锦上添花；所有 UX 规格须引用本分级。
- **落地点建议**：MVP 强制达成 **Basic 全项 + Standard 主体**（Standard 中「色盲模拟测试」可先以工程侧 dev 工具 + 设计侧审查落地，玩家端 CVD 滤镜可作为 Standard 尾声项）；**Comprehensive** 作为核心层（上线必备）与长线运营的分阶段目标。

## 1. 三级分级定义

### 1.1 Basic（最低合规 / 上线底线，solo 也必须满足）
对应 art-bible §8 全部基线，是「不依赖颜色即可玩、字能看清、版面不破」的最低保障。
- **A. 文字对比度**：正文（Body/Caption）≥ 4.5:1，大标题（H1/H2）≥ 3:1（WCAG AA 文本基准）。
- **B. 高对比模式开关**：全局可切换高对比主题（深墨底 #122426 + 月白 #E8ECEF、加描边/投影双重边界），默认提供入口且可持久化。
- **C. 文本缩放 100%–130% 不破版**：基于弹性栅格（8 倍数），缩放时布局 reflow 不溢出、不裁切；数值用 tabular nums 防跳。
- **D. 关键反馈三重标识（图标 + 数字 + 颜色）**：战斗伤害/治疗/格挡一律「图标 + 数字 + 颜色」三通道——治疗 = 绿十字 +「+N」+ 青碧；伤害 = 红剑 +「−N」+ 朱砂；格挡 = 蓝盾 +「−N 挡」+ 青碧。任何单通道失效仍可理解。
- **E. 色盲冗余（基础编码，Basic 强制）**：
  - 稀有度：**颜色 + 边框纹理 + 角星数量（1/2/3）** 三重冗余（N 素灰素边 / R 青碧细边 / SR 鎏金浮雕边 + 角饰 / SSR 紫宸虹光边 + 3 钻星；UR 双描 + 循环光），不靠颜色单独区分。
  - 五行：**图标 + 形状（圆/三角/方）** 冗余（金=剑形三角、木=叶形圆、水=水纹圆、火=丹形三角、土=方）；形状本身可区分，不依赖色相。

### 1.2 Standard（推荐 / 核心层上线目标）
在 Basic 之上补齐「可测试、可调控、可读层级」的可访问性。
- **G. 色盲模拟测试 + 玩家端 CVD 滤镜**：工程侧提供 Deuteranopia / Protanopia / Tritanopia 三型模拟（dev 工具 + 美术审查流程强制）；设置内提供**可选** CVD 滤镜开关（对主色板做色相安全重映射或后处理 shader），三重冗余之上再加一道保障。
- **H. 动态文本（Dynamic Text）**：UI 文本按容器自适应、尊重系统字体放大偏好（OS dynamic type）；长文本/本地化溢出走省略号 + 展开而非裁切；字号上限不破坏控件热区。
- **I. 减少动效选项（Reduce Motion）**：全局「减少动效」开关，关闭非必要动画——屏幕震动、粒子密度、视差、SSR/UR 的循环光扫/动态光效、抽卡长演出；保留状态变化的「静态等效反馈」（图标/数字/边框仍更新）。
- **J. 触控热区 ≥ 44×44px 强制**：移动端所有可交互控件最小命中区 44×44px（含按钮间安全间距），自动化校验纳入构建管线。
- **K. 可读性字体层级落地**：H1–H4 / Body / Caption / Stat 六层级完整落地，层级靠字号 + 字重 + 留白区分（art-bible §3），不靠纯颜色；书法/宋体标题仅用于装饰性大标题，正文强制黑体可读性取向。

### 1.3 Comprehensive（完整 / 长线运营目标）
面向更广障碍群体与极端环境。
- **L. 手柄 / 键盘全导航**：完整 Tab 顺序 + 方向键聚焦 + 焦点环（focus ring）清晰可见 + 逻辑阅读顺序；手柄可遍历全部菜单/战斗操作；不可聚焦的装饰元素显式排除。
- **M. 屏幕阅读器友好**：所有交互元素含语义标签 / 无障碍名（accessibility name）；战斗日志、抽卡结果、养成变化用 live region 播报；焦点移动有 announcements；图标按钮有文字等价。
- **N. 字幕 / 音频可视化**：全部剧情对话、提示语音配字幕（art-bible §3 正文 ≥16sp）；关键音频提示（如回合开始、克制命中、Boss 警告）提供可视化等价（屏幕边脉冲 / 图标闪烁 / 律动条），不依赖声音。
- **O. 多语言 / 本地化可访问**：文本扩展安全（CJK→EN/其他语言长度变化不破版）、字体回退链（Fallback font）、RTL 安全预留；字幕与 UI 同步本地化。
- **P. 弱网 / 低性能降级模式**：「性能/省电模式」一键降级——降纹理分辨率、关 3D 演出余量、降粒子上限、降帧目标（移动 30fps 优先稳帧）；降级后仍满足 Basic 对比度与三重标识。

## 3. 双端适配要点
断点口径（art-bible §7 / A5）：≥1024 横屏多栏 / 768–1024 混合 / <768 竖屏单列。

### 3.1 PC 横屏（≥1024px）
- **导航**：键盘 Tab/方向键/Enter/Esc 为主路径；焦点环高可见；逻辑 tab 顺序与视觉阅读顺序一致。
- **悬停反馈**：hover 灵气粒子需配非颜色提示（hover 同时加描边加厚 + 图标态变化），避免只靠发光。
- **高对比**：PC 提供深/浅两套高对比主题切换；设置内独立记忆。
- **文本缩放**：窗口内 UI 缩放滑块（100–130%）+ 监听 OS 缩放；多栏弹性布局，缩放不破版。
- **性能降级**：PC 性能富余，仍提供「性能模式」关 3D 演出与高密粒子，作为 Comprehensive 兜底。
- **户外强光**：非主要场景，由高对比模式兜底。

### 3.2 移动竖屏（<768px）
- **触控热区**：所有可交互控件 ≥44×44px 强制（Standard J），含间距；底部 Tab 关键操作拇指可达。
- **户外强光对比**：深墨底 #122426 + 月白 #E8ECEF 而非纯黑白；提供「户外模式」（提对比、降面板透明度、压高光）选项，默认按环境光传感器提示。
- **文本缩放**：同步 OS 字体放大 + 应用内 100–130% 滑块；竖屏单列布局天然抗破版。
- **减少动效**：移动性能敏感，首次进入按设备档位建议开启「减少动效」；默认降粒子/视差。
- **旋转/分辨率**：响应式断点 + 输入抽象（art-bible §7 / A5），旋转与分辨率切换不破版、不丢焦点。
- **音频可视化**：移动常外放/静音，关键提示优先用屏幕脉冲/图标（Comprehensive N）。

## 4. 与美术圣经 §8 的对齐说明 + Phase 1 视觉锚点可访问性备注

### 4.1 与 §8 的对齐
- **来源映射**：art-bible §8 的四条 solo 轻量基线 = 本规格 **Basic** 级（A 对比度、B 高对比、C 文本缩放、D 三重反馈、E 色盲冗余）。本次升级为三级，Standard/Comprehensive 在其上扩展，不推翻 §8。
- **字体层级（§3）** → Standard K 落地；**双端热区/断点（§7）** → Standard J 强制校验。
- **§2.3 跨亮度自适应**（深墨底 + 描边/投影双重边界 + 高对比开关）→ Basic B 与移动户外策略（§3.2）共同实现。
- **§8「轻量定位：UX 规格引用本分级即可」** → 升级为：**所有 UX/系统 GDD 必须引用本分级的对应级**，替换原 §8 轻量表述。
- **建议**：Phase 3 美术圣经 §8 改写为「详见 art/accessibility-spec.md（Basic/Standard/Comprehensive 三级）」，避免双文档维护冲突。

### 4.2 Phase 1 视觉锚点可访问性备注
- **锚点 5 · 灵宠 vs 法宝对比（强推荐复用为类别冗余编码）**：左灵宠（活物·暖玉金光·圆润有机·柔光粒子·发光眼）vs 右法宝（器物·冷青金线·几何硬边·对称符文·悬浮自转），统一墨青 #1F3A3D 背景。**形状与质感天然区分活物与器物，不依赖颜色**——这直接利于色盲与低视力玩家辨识灵宠/法宝类别。建议在 UI 中对「灵宠/法宝」类资产复用该形状语言（圆润 vs 几何硬边）作为第 N 类冗余编码（呼应 B7 法宝/灵宠独立养成线的视觉差异）。
- **锚点 4 · SSR 仙品卡框**：已含「顶部三钻星稀有度横幅 + 紫宸虹光边框 + 角饰」，直接服务 Basic E 的稀有度角星/边框冗余，出图时确保角星与边框纹理在灰度下仍清晰。
- **锚点 1 / 2 · 御剑长空 / 悬浮宗门仙山**：大场景氛围图，需保证与前景卡牌/UI 的对比度（§6 已要求不抢前景）；作为背景时降饱和、加暗角，避免干扰三重标识阅读。
- **锚点 3 · 水系剑修立绘**：角色靠剪影/发色/本命法宝辨识（§4 核心视觉符号），建议立绘下方常驻「门派/五行图标 + 形状」标签，与五行冗余（Basic E）对齐。

## 5. 工程落地接口建议（供 Phase 3 架构预留）
> 下列为美术侧提出的接口契约，供 engineering-lead 在 Phase 3 架构落地；不直接改动工程代码。
- **集中式设置单例 `AccessibilitySettings`**（AutoLoad/单例）：持有 `high_contrast: bool`、`reduce_motion: bool`、`text_scale: float (1.0–1.3)`、`color_blind_mode: enum(NONE/DEUTER/PROTAN/TRITAN)`、`cvd_filter: bool`、`performance_mode: bool`、`dynamic_text: bool`；变更时 emit 信号（`accessibility_changed`）供 UI 主题与 shader 订阅。
- **主题系统**：单一 `Theme` 资源 + 高对比主题覆盖层；稀有度/五行/反馈三重的颜色、边框纹理、角星、形状绑定到主题常量，禁止硬编码色值。
- **CVD 滤镜**：根 Viewport 后处理 shader 或主题色重映射（Standard G），按 `color_blind_mode` 切换。
- **动效总线**：全局 `MotionScale`（reduce_motion 时 0），VFX/粒子/视差/光扫读取该值；状态变化保留静态等效反馈。
- **文本系统**：统一 `Label`/`RichTextLabel` 封装，读取 `text_scale` + `dynamic_text`，tabular nums 全局默认；溢出走省略号 + 展开。
- **焦点导航**：Control 节点 `focus_mode` 规范 + 全局焦点环样式；手柄/键盘遍历（Comprehensive L）+ 屏幕阅读器 `accessibility_name` / live region（Comprehensive M）。
- **触控校验**：构建管线 lint 校验移动端控件 ≥44×44px（Standard J）。
- **降级模式**：`performance_mode` 联动纹理/粒子/3D 演出降级（Comprehensive P），降级后断言 Basic 仍满足。

## 一句话总结
本规格把美术圣经 §8 的 solo 轻量基线升级为 **Basic（上线底线：对比度/高对比/缩放/三重反馈/色盲冗余）/ Standard（推荐：CVD 滤镜·动态文本·减少动效·44px 热区·字体层级）/ Comprehensive（完整：全导航·屏幕阅读·音频可视化·本地化·弱网降级）** 三级契约，并给出双端差异与工程接口预留建议，供 Phase 3 架构落地。
