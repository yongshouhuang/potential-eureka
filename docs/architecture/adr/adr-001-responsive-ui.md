# ADR-001 · 双端响应式 UI 框架方案

- **Context**：R3（双端返工贵）；art-bible§7 断点（≥1024/768–1024/<768）；同一游戏双端体验统一。
- **Decision**：**单套 UI 描述 + 断点驱动布局切换**（Control/Container 响应式 + `UIThemeController` 切换布局变体/Theme），**不另出独立场景**。可访问性(形状冗余/44×44/高对比/tabular nums)并入 UI 组件基线。
- **Consequences**：✓ 避免双份维护、8 栅格+主题统一、改一处两端生效；✗ 复杂屏需布局变体逻辑（可接受，lean）。风险：过度响应式致单屏逻辑膨胀 → 控制清单约束"每屏布局变体 ≤3"。
